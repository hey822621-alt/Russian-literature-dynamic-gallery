# 俄罗斯文学的流动画廊 · 动态作品情节版

Astro 静态站。五位作家 Cover Flow + 各作品主要情节叙事画廊，画面缓动、光影流动、移动端滑动、减少动态效果支持。中文仿宋系统字体，俄文 Times New Roman。

## 发布到 Cloudflare

将本 ZIP 解压后，上传**全部文件**到现有 GitHub 仓库 `hey822621-alt/russian-literature-gallery` 根目录，替换同名文件后提交。Cloudflare 若已开启 GitHub 自动部署，将自动重新构建。请确认项目类型及命令是否正确：Astro / `npm run build` / `dist`。

## 绘画素材状态（重要）

为《叶甫盖尼·奥涅金》《上尉的女儿》《死魂灵》《罪与罚》《战争与和平》《樱桃园》制作了各 5 幅分别对应叙事节点的独立图片素材：这些是既有概念页插画的裁切与放大，并非新画的高清原画；部分构图仍属概念近似，需逐幅核对原著与继续精绘。其他主要作品提供逐情节卡片及独立展示图片**习作占位**，不能视为已经完成与剧情严格对应的原创插画；网站也在相应作品底部明确提示。果戈里的《彼得堡故事集》按《外套》《鼻子》《涅瓦大街》《狂人日记》各配一幅，亦属习作占位。请勿把全部配图当成已完成的出版级文学插画。

## 本地运行

``npm install`` 之后执行 ``npm run dev`` 或 ``npm run build``。

画面动态采用纯 CSS 和原生 JS，不需额外依赖，不上传用户个人数据。
